# T15.001 / T16.001 — synthetic measured-state reconstruction and information acquisition

Exploratory protocol, written before execution. Refs #1, #15, #16, #17. No clinical records, thresholds, decisions, diagnoses or claims. Real PhysioNet qualification remains required. Artificial measurements are unitless; target is the withheld measured value at cutoff, never the simulator latent state or future outcome.

Seed 7139; 480 development, 160 calibration, 240 test subjects (120 in each of two test settings, second shifted). One cutoff per synthetic subject, six past readings with missingness, observed regime, three optional same-time auxiliary readings. Keep subject and setting identities separate; training/calibration never use test subjects. No future features. Only past observations and revealed auxiliary values visible to reconstruction; selection policy receives no hidden measurements or target. All candidates have unit synthetic acquisition cost. No implications for investigation delay or clinical utility.

T15: compare development mean, last observation carried forward, bounded linear trend, and development-fitted ridge state reconstruction (penalty 1). Primary descriptive MAE, secondary RMSE and split-conformal 90% interval coverage/width using calibration subjects only. Report test settings separately. No thresholds tuned on test.

T16: same ridge reconstruction model per acquired-subset for every policy. On development only, four-fold out-of-fold estimation of squared-error reduction per candidate; fit fixed panel order from mean single-acquisition gains, greedy expected gain conditional on regime and subset, and ridge marginal-gain estimator with visible context; all use the same development outcomes. Compare fixed, regime-greedy and context-learned policies at nested budgets 0, 1, 2, 3. At each decision a trusted replay reveals only chosen measurement after selection; no target feedback. Primary mean squared reconstruction error at one acquisition, descriptive paired differences at all budgets, report shift strata and conformal coverage at each policy/budget. Compare fixed order and greedy as real comparators, not oracle. Exact candidate pool and measurement count matched, training/inference costs recorded separately. Negative results retained, no post-hoc tuning. Additional 90% intervals are calibrated on held-out calibration partition; exchangeability may fail under shift.

Use existing structural dataset and experiment contracts/hash helper; companion continuous and ranking/calibration/mutation metric functions retain explicit denominators. Do not misuse classification error counts for continuous values. Version raw synthetic prediction traces and a compact summary; run twice with same seed and compare canonical results, record runtime separately. No canonical task accepted; T00/T11/T14 prerequisites and independent clinical reference qualification remain open.
