# T18.001 — finite-domain counterexample selection (exploratory)

Refs #19, #1, #12, #15; stacked after #23. Research only, no real clinical rule or patient data. This local pilot is an exploratory precursor while T00.002, T00.003 and T11.001 acceptance remains outstanding; not a confirmatory protocol or completion receipt.

- Domain: x,y in {0,...,4}, flags c,d in {0,1}; 100 cases. Original rule: Boolean function of x>=t, y>=u, c,d; t,u in {1,2,3}.
- Eight structural families: and/or/conditional development, majority calibration reserved unused, nand/gated/xor/two_paths held out. Each family has nine threshold instances. Hold out entire structural families, not individual rows; mutation operator families reused, so this is not a mutation-family holdout.
- Mutate one atomic predicate: boundary shift, inversion, constant true/false, flag inversion. Exhaustive truth-table oracle independently expressed from executable Boolean evaluator; compare every domain case for every family, threshold and mutation. Exclude mutants equivalent to original and collapse identical full-domain difference signatures within instance. Distinct signatures across instances are not independent observations.
- Arms: 8 distinct cases per instance; random uniform without replacement, 20 replicates using seed 1107 plus instance/repeat offset; deterministic threshold-boundary selector, learned linear regression of fraction of distinct mutants killed trained on all development cases only. The deterministic and learned selectors share flag stratification and deterministic tie-break. Both see original rule and same domain; neither sees test mutant outputs before selection. Development labels are generated by the exhaustive oracle. Fixed 100 gradient steps, learning rate 0.15; no post-hoc tuning or calibration.
- Primary descriptive metric: macro mean per-instance proportion of distinct non-equivalent defect signatures exposed; average random replicates within instance. Report four family strata, paired comparisons, unique selected cases and raw kill identities. No inferential p-values or clinical efficacy claim with four test families. A deterministic oracle is independent in expression, not independently human-adjudicated.
- Record exact source and test blobs, Python environment, seed, command, raw output hash, elapsed runtime and failure logs. Regenerate twice to check canonical byte reproducibility. Runtime not embedded in deterministic raw JSON. The raw output schema is task-specific mutation coverage, not classification accuracy; do not force it into the case-level denominator contract in #23.
- Next: extend to independently specified held-out rule and mutation families and qualified CQL, compare stronger diverse boundary/constraint solvers and learned adaptive selection. Preserve negative findings; do not use test outcomes for confirmatory hyperparameter selection.
