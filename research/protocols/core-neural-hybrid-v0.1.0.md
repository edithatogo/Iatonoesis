# Eight-family neural/hybrid follow-up — exploratory protocol v0.1.0

Refs T00.003/005/006, T01–T08 and T14 (#1–#9, #15). Use the original #32 frozen synthetic dataset (seed 17, exact original freeze-file SHA-256 a58671945b5b23f9cb09cf5b0d949cd89fc85166952087ecf2a3351a4693c081; source fc2d308a6055b1e689cb031ba3732256fe342690). All eight test sets are already exposed: exploratory follow-up only, not confirmatory or independent clinical evidence. No patient data or pretrained weights. Freeze this protocol before full 60-epoch execution; small acceptance smoke tests preceded protocol commit. Do not tune on test scores.

- E02 listwise relative-layout candidate MLP; E13 listwise fixed-candidate MLP (top-1, not full rank evaluation).
- E04, E17, E22 feature-token GRU sequence models. E04 learned pending-status plus deterministic tuple extraction, not end-to-end span tagging; E22 pre-extracted event features, not raw clinical verification.
- E07 directed four-step message-passing GNN, with independently trained zero-message ablation. Exact graph traversal remains authoritative.
- E11 and E20 structured-feature MLP; toy judgments, not credentialing or clinical evidence evaluation.
- One fixed seed, 60 full-batch Adam epochs at learning rate .02; 32 MLP hidden units, 16/24 embedding/GRU units, 24 graph hidden units. Development only for fitting and vocabulary. No test data labels for training. CPU deterministic algorithms, one thread. Separate training and inference seconds; same test cases, not matched training/compute budgets. Original classical model retrained and compared, deterministic comparator kept.
- Arms: rules, classical, raw neural, guarded neural, calibrated fallback, agreement-only. Guard disallows false support, incompatible referral destinations, unjustified completion and clearing unknown discharge obligations. Fallback can replace an unresolved rule only when >=4 eligible retained calibration proposals have no observed error; threshold grid .5,.6,.7,.8,.9,.95, choose lowest qualifying; otherwise no fallback. This is intentionally conservative, not statistical safety certification. Agreement abstains on disagreement. Treat abstentions as missed targets in set F1; separate coverage and accuracy. Do not credit human resolution.
- Report per-arm counts, predictions SHA-256, weights SHA-256, training identity, elapsed seconds, F1, risk/coverage, paired grouped 200-draw intervals and critical-error diagnostics. GNN messages versus zero-message. Four or five test groups imply descriptive uncertainty only. No global score, no claim of architecture superiority or real staff/patient outcomes.
- Independently authored, rights-qualified external data, source-specific metrics (GriTS, span/tuple F1, graph edge/site holdout, graded nDCG, selective risk, evidence spans and step checks), specialist pretrained models, independent calibration and test contamination audit remain required. Do not displace active #34/36/40/41 source or experiment lanes.

Runtime: optional isolated Python 3.13.5 / torch 2.10.0+cpu; do not add PyTorch to base Python 3.15.2 dependencies. Ordinary CI may explicitly skip torch-dependent tests; that is not evidence of neural execution. No remote inference or paid compute. Use matched blob and data hashes and reproduce raw predictions. Negative findings and absent benefit are publishable evidence within the exploratory scope.
