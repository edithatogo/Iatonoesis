# T02 external biomedical disease spans — exploratory cross-source protocol v0.1.0

Owners T02.001/006–009 (#3), T00 (#1), T09 (#10), T11 (#12), T14 (#15). Extends B04 and the E05 span-extraction component, not E04 obligation extraction or clinical assertion/experiencer labels. Author-supplied NCBI Disease Corpus: Doğan, Leaman and Lu, J Biomed Inform 2014, DOI 10.1016/j.jbi.2013.12.006, PMID 24393765; https://www.ncbi.nlm.nih.gov/research/bionlp/Data/disease/. Original files mirrored at https://github.com/openbiocorpora/ncbi-disease/tree/413ebc68601670d9a36b041535c77112c5e629da, pinned Git blob hashes/lengths and US government public-domain notice. Preliminary source inspection: original 593/100/100 documents (one identical train duplicate; one train offset mismatch), 5145/787/960 annotations. Quarantine offset-invalid training documents, count duplicate/overlap removals; fail on invalid test or calibration spans. NCBI annotation types SpecificDisease, DiseaseClass, CompositeMention, Modifier all treated as disease spans; exact offset match, no text reproduction. Public PubMed abstracts and annotation rights remain distinct: internal bounded research processing, no source text or training weights distributed.

Cross-source holdout: Li et al. Database 2016, DOI 10.1093/database/baw068, PMID 27161011, original BC5CDR corpus v010516 via https://huggingface.co/datasets/bigbio/bc5cdr. Dataset script reports Public Domain Mark 1.0; verify original archive notice, immutable revision, expected size 20,403,150 bytes and published LFS SHA-256 before use. Parse only original official 500-document test file, disease spans; no chemical/relation inference. If source/rights/format integrity unavailable, report external arm unavailable rather than invent scores. Remove duplicate PMIDs and normalized text across source partitions in order NCBI test, calibration, development, then external. No near-duplicate or pretraining-exposure guarantee. Freeze exact input/reference/partition digests, deterministic SHA-based selection of 256 NCBI training and 100 external test documents after overlap removal; retain all NCBI calibration/test. No source-derived prompts or test tuning.

Compare development-only longest case-insensitive dictionary, small development-trained token BIO MLP (hashed 256 contextual lexical features, 32 hidden units, fixed seed 17, 25 Adam epochs), and pretrained clinical NER transfer d4data/biomedical-ner-all (DistilBERT, MACCROBAT case-report training, Apache-2.0 card, 265,722,260-byte safetensors). Resolve immutable model revision, verify weight digest, record config/tokenizer hashes before inference; no remote code, no pickle, no third-party inference calls. Map only B/I-Disease_disorder to disease; label mismatch/annotation-policy shift must be disclosed. Documents exceeding 512 pretrained tokens explicitly abstain, no truncated gold. Compare exact spans, unseen training surface recall, document exact match, false positives, coverage and review burden at 50/75/100% document retention; budget infeasibility explicit. Confidence-ranked coverage is retrospective diagnostic, not prospective policy. Separate fit/load/inference times; matched documents/review budgets, not matched compute. Paired document bootstrap descriptive. Fallback dictionary-empty proposals only, use calibration labels alone and existing conservative gate (>=30 proposals with upper Wilson error <=.20); no benefit claimed if inactive. Agreement arm abstains when exact proposed span sets disagree. No review credited as correct. Output only offset sets, hashed IDs and aggregate metrics/digests; no abstracts, entity strings, weights or patient records. No clinical effectiveness claim, no all-family reference admission. Local test-first failure then five tests passed on Python 3.13.5, exact hosted runtime and inference required.
