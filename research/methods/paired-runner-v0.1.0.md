# Paired research runner

T00.003 and T00.005 (#1); dependent on #23. The runner accepts an experiment contract, dataset manifest, ID-keyed JSON input and reference objects, and trusted local adapters. SHA-256 hashes bind the input object, reference object, experiment config and split manifest. Each adapter receives a deep copy of its input only; the caller must qualify its actual model revision, licence, training isolation and environment. Only frozen test cases are passed. Predictions, gold and group IDs are retained for paired comparison. Raw prediction hashes are deterministic for deterministic adapters; elapsed time is intentionally observational. Non-executed arms carry explicit status and no metrics; partial predictions are separate failure artifacts. Review/abstention is not counted as successful adjudication. Do not publish raw artifacts unless rights and privacy are cleared.

Shared set metrics: micro precision, recall and F1, exact case accuracy, coverage, selective accuracy, explicit denominators and counts. Undefined ratios are null. For single-label classification use singleton sets; for multi-label or tuple extraction use lists of unique JSON values. The paired cluster bootstrap resamples declared groups with replacement and computes challenger minus baseline micro-F1; reports valid/attempted draws and percentile limits. With small numbers of clusters these intervals are descriptive and not robust population inference. Ranking, calibration, cost, latency distributions and task-specific outcome measures remain separate extensions. No sandbox, hard preemptive timeout, external data acquisition, or clinical qualification. Time budgets are checked before and after trusted adapter calls; a hung call requires process-level isolation in future.
